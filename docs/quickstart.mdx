# Quickstart

## Install the Codex Plugin

In Codex, open **Plugins**, choose **Add plugin marketplace**, and enter either
`agentrhq/webcmd` or `https://github.com/agentrhq/webcmd`. Install **Webcmd**
from that marketplace, then start a new task. On first use, the integration
installs the npm CLI automatically if `webcmd` is missing.

It includes exactly one bundled skill, `webcmd-browser`. Do not also add that
skill with `webcmd skills add` in Codex.

## Install the Claude Code Plugin

```bash
claude plugin marketplace add agentrhq/webcmd
claude plugin install webcmd@webcmd
```

This installs exactly one bundled skill, `webcmd-browser`. Do not also add that
skill with `webcmd skills add` in Claude Code.

## Other Agents or Plugin-Free Setup

Webcmd requires Node.js 20.6+ and an agent harness that can run shell commands.

```bash
npm install -g @agentrhq/webcmd
webcmd skills add
```

When prompted, choose Claude, Codex, another supported harness, or a custom
skills path.

## Ask Your Agent

```text
Use Webcmd to find five companies currently hiring Forward Deployed Engineers.
Return company, role, location, a one-sentence description, and the source URL.
Research only: do not apply, contact anyone, or change my account.
```

## What Happens Next

The agent creates a browser Session, inspects the live website, and returns the
requested results. Webcmd retains useful, verified knowledge of the site's
structure so another agent can start faster next time. If the live page no
longer matches that memory, the agent inspects the page again and updates its
understanding.

## Try Another Prompt

```text
Use my logged-in `work` profile to collect open invoices from the Acme dashboard.
Return invoice_id, customer, due_date, amount, status, and detail_url. Pause if I
need to sign in, never ask me to paste credentials into chat, and do not change
any records.
```
