# Skills

The bundled install is exactly one skill, `webcmd-browser`. It teaches an agent
how to create and manage Sessions, inspect live pages, run browser programs,
handle sign-in handoffs, and verify results.

## Install in Codex

Open **Plugins**, choose **Add plugin marketplace**, enter `agentrhq/webcmd`,
and install **Webcmd**. The Codex integration bundles this skill and installs
the npm CLI on first use if `webcmd` is missing. Start a new task after
installation.

Do not also add the skill with `webcmd skills add` in Codex.

## Other Agents or Plugin-Free Setup

Run `webcmd skills add` to install or refresh `webcmd-browser` for your agent.
For raw browser work, the agent creates a named Session, keeps its immutable,
Profile-scoped ID, and passes it at the root of every browser command:

```bash
webcmd --profile work session create "Work Project" -f json
webcmd --profile work --session work-project-k7 browser tabs
```
