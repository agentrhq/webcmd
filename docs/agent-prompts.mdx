# Prompt Cookbook

Describe the website, outcome, required fields, authentication context, and
safety boundaries. The agent handles browser navigation, inspection, and
verification.

## Research a Public Website

```text
Use Webcmd to find five companies currently hiring Forward Deployed Engineers.
Return company, role, location, a one-sentence description, and the source URL.
Research only: do not apply, contact anyone, or change my account.
```

## Complete a One-Off Browser Task

```text
Use Webcmd on https://example.com/jobs to find product-design roles in London.
Return title, company, location, salary_text, posted_at, and URL. Do not apply,
create an account, or change saved searches.
```

## Use a Logged-In Website

```text
Use my logged-in `work` browser profile to read invoices from the Acme billing
dashboard. Return invoice_id, customer, due_date, amount, status, and detail_url.
If authentication is required, pause for me to sign in directly in the browser.
Never request credentials in chat, and do not change invoice or account data.
```

## Compare Results Across Sites

```text
Use Webcmd to compare the current pricing pages for these three developer tools.
Return product, entry price, included usage, overage price, enterprise option,
source URL, and the date checked. If a value is not stated, return null instead
of guessing. Do not start a trial or submit a form.
```

## Inspect a Repository Workflow

```text
Use Webcmd with my `work` profile to review the open pull requests assigned to
me on GitHub. Return repository, number, title, author, updated_at, review state,
and URL. Do not comment, approve, merge, close, or modify any pull request.
```

## Work Across Several Pages

```text
Use one Webcmd browser Session to inspect the documentation, changelog, and
pricing pages for this product. Summarize what changed in the latest release,
which plans include the feature, and any limitations, with a source URL for
every claim. Keep the task read-only.
```

## Ask for a Plan First

```text
Before using the browser, propose the shortest safe plan for collecting open
invoice data from the Acme dashboard. Include the pages you expect to inspect,
the fields to return, the `work` profile requirement, possible sign-in handoff,
and actions that require my approval. Do not open or modify anything until I
approve the plan.
```
