# webcmd-plugin-oeis

Webcmd commands for oeis.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/oeis
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd oeis search` | Search OEIS sequences by keyword or numeric pattern |
| `webcmd oeis sequence` | Full OEIS sequence detail by A-number (terms, name, keywords, formula counts) |
