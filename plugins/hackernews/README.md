# webcmd-plugin-hackernews

Webcmd commands for hackernews.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/hackernews
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd hackernews ask` | Hacker News Ask HN posts |
| `webcmd hackernews best` | Hacker News best stories |
| `webcmd hackernews jobs` | Hacker News job postings |
| `webcmd hackernews new` | Hacker News newest stories |
| `webcmd hackernews read` | Read a Hacker News story and its comment tree |
| `webcmd hackernews search` | Search Hacker News stories |
| `webcmd hackernews show` | Hacker News Show HN posts |
| `webcmd hackernews top` | Hacker News top stories |
| `webcmd hackernews user` | Hacker News user profile |
