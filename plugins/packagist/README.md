# webcmd-plugin-packagist

Webcmd commands for packagist.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/packagist
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd packagist package` | Fetch a Packagist package's metadata (version, downloads, license, repo, GitHub stars) |
| `webcmd packagist search` | Search Packagist (PHP / Composer) packages by keyword |
