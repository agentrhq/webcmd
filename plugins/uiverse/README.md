# webcmd-plugin-uiverse

Webcmd commands for uiverse.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/uiverse
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd uiverse code` | Export Uiverse component code (HTML, CSS, React, or Vue) |
| `webcmd uiverse preview` | Capture a screenshot of the Uiverse preview element |
