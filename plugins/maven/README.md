# webcmd-plugin-maven

Webcmd commands for maven.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/maven
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd maven artifact` | Fetch a Maven Central artifact's version history (groupId:artifactId[:version]) |
| `webcmd maven search` | Search Maven Central by keyword (artifact name, groupId, tag) |
