# webcmd-plugin-homebrew

Webcmd commands for homebrew.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/homebrew
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd homebrew cask` | Fetch a Homebrew cask's metadata (version, homepage, deprecation, download URL) |
| `webcmd homebrew formula` | Fetch a Homebrew formula's metadata (version, license, deps, deprecation, source) |
| `webcmd homebrew popular` | List most-installed Homebrew formulae or casks (Homebrew's analytics ranking) |
