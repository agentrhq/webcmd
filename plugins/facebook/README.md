# webcmd-plugin-facebook

Webcmd commands for facebook.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/facebook
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd facebook add-friend` | Send a friend request on Facebook |
| `webcmd facebook events` | Browse Facebook event categories |
| `webcmd facebook feed` | Get your Facebook news feed |
| `webcmd facebook friends` | Get Facebook friend suggestions |
| `webcmd facebook groups` | List your Facebook groups |
| `webcmd facebook join-group` | Join a Facebook group |
| `webcmd facebook login` | Open facebook login |
| `webcmd facebook marketplace-inbox` | List recent Facebook Marketplace buyer/seller conversations |
| `webcmd facebook marketplace-listings` | List your Facebook Marketplace seller listings |
| `webcmd facebook memories` | Get your Facebook memories (On This Day) |
| `webcmd facebook notifications` | Get recent Facebook notifications (includes unread / time / url / notif_id / notif_type columns) |
| `webcmd facebook profile` | Get Facebook user/page profile info |
| `webcmd facebook search` | Search Facebook for people, pages, or posts |
| `webcmd facebook whoami` | Show the current logged-in facebook account |
