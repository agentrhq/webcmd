# webcmd-plugin-nuget

Webcmd commands for nuget.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/nuget
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd nuget package` | Full NuGet package version history (catalogEntry per release) |
| `webcmd nuget search` | Search NuGet packages by keyword |
