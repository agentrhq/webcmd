# webcmd-plugin-indeed

Webcmd commands for indeed.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/indeed
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd indeed job` | Read the full Indeed job posting by jk (job key) |
| `webcmd indeed search` | Indeed keyword job search (rendered DOM via browser session, US site) |
