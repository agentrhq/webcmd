# webcmd-plugin-wttr

Webcmd commands for wttr.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/wttr
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd wttr current` | Current weather conditions for a location (city, lat,lon, or airport code) |
| `webcmd wttr forecast` | Multi-day weather forecast (up to 3 days, wttr.in free tier max) |
