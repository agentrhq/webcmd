# webcmd-plugin-reuters

Webcmd commands for reuters.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/reuters
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd reuters article-detail` | Reuters Reuters article detail:title/author/body text |
| `webcmd reuters login` | Open reuters login |
| `webcmd reuters search` | Reuters Reuters news search |
| `webcmd reuters whoami` | Show the current logged-in reuters account |
