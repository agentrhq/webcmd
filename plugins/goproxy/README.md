# webcmd-plugin-goproxy

Webcmd commands for goproxy.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/goproxy
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd goproxy module` | Latest version + VCS origin metadata for a Go module on proxy.golang.org |
| `webcmd goproxy versions` | Published version tags for a Go module (newest first), optionally with publish times |
