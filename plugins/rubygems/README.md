# webcmd-plugin-rubygems

Webcmd commands for rubygems.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/rubygems
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd rubygems gem` | Fetch a RubyGems.org gem's metadata (version, downloads, license, links) |
| `webcmd rubygems search` | Search RubyGems.org gems by keyword |
