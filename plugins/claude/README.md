# webcmd-plugin-claude

Webcmd commands for claude.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/claude
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd claude ask` | Send a prompt to Claude and get the response |
| `webcmd claude detail` | Open a Claude conversation by ID and read its messages |
| `webcmd claude history` | List conversation history from Claude /recents |
| `webcmd claude login` | Open claude login |
| `webcmd claude new` | Start a new conversation in Claude |
| `webcmd claude read` | Read the current Claude conversation |
| `webcmd claude send` | Send a prompt to Claude without waiting for the response |
| `webcmd claude status` | Check Claude page availability and login state |
| `webcmd claude whoami` | Show the current logged-in claude account |
