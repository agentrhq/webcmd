# webcmd-plugin-jira

Webcmd commands for jira.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/jira
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd jira attachments` | Jira issue attachment metadata |
| `webcmd jira comments` | Jira issue comments as Markdown |
| `webcmd jira issue` | Jira issue detail normalized for agents (description, comments, attachments, links) |
| `webcmd jira links` | Jira issue links |
| `webcmd jira search` | Search Jira issues with JQL |
