# webcmd-plugin-pixiv

Webcmd commands for pixiv.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/pixiv
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd pixiv detail` | View illustration details (tags, stats, URLs) |
| `webcmd pixiv download` | Download illustration images from Pixiv |
| `webcmd pixiv illusts` | List a Pixiv artist's illustrations |
| `webcmd pixiv login` | Open pixiv login |
| `webcmd pixiv ranking` | Pixiv illustration rankings (daily/weekly/monthly) |
| `webcmd pixiv search` | Search Pixiv illustrations by keyword |
| `webcmd pixiv user` | View Pixiv artist profile |
| `webcmd pixiv whoami` | Show the current logged-in pixiv account |
