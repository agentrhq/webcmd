# webcmd-plugin-steam

Webcmd commands for steam.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/steam
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd steam app` | Steam storefront detail for a single app id |
| `webcmd steam search` | Search the Steam storefront by name keyword |
| `webcmd steam top-sellers` | Steam top selling games |
