# webcmd-plugin-defillama

Webcmd commands for defillama.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/defillama
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd defillama protocol` | Single DefiLlama protocol details (current TVL, mcap, chains, twitter, github, description) |
| `webcmd defillama protocols` | Top DeFi protocols on DefiLlama by current TVL (slug, name, category, TVL, mcap, change_1d/7d, chains) |
