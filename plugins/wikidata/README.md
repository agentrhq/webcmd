# webcmd-plugin-wikidata

Webcmd commands for wikidata.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/wikidata
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd wikidata entity` | Fetch a Wikidata entity by Q/P/L id (label, description, aliases, claim summary) |
| `webcmd wikidata search` | Search Wikidata items by keyword (returns Q-IDs) |
