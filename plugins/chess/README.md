# webcmd-plugin-chess

Webcmd commands for chess.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/chess
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd chess analyze` | Open a Chess.com game in the browser analysis board |
| `webcmd chess game` | Chess.com single-game detail (white, black, result, ECO, time control) by full game URL |
| `webcmd chess games` | Chess.com recent games for a player, newest first |
| `webcmd chess stats` | Chess.com player ratings + win/loss record across game kinds |
