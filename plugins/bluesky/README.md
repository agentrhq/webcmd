# webcmd-plugin-bluesky

Webcmd commands for bluesky.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/bluesky
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd bluesky feeds` | Popular Bluesky feed generators |
| `webcmd bluesky followers` | List followers of a Bluesky user |
| `webcmd bluesky following` | List accounts a Bluesky user is following |
| `webcmd bluesky profile` | Get Bluesky user profile info |
| `webcmd bluesky search` | Search Bluesky users |
| `webcmd bluesky starter-packs` | Get starter packs created by a Bluesky user |
| `webcmd bluesky thread` | Get a Bluesky post thread with replies |
| `webcmd bluesky trending` | Trending topics on Bluesky |
| `webcmd bluesky user` | Get recent posts from a Bluesky user |
