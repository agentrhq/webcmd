# webcmd-plugin-openalex

Webcmd commands for openalex.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/openalex
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd openalex search` | Search OpenAlex Works (papers, books, preprints) by keyword |
| `webcmd openalex work` | Fetch a single OpenAlex Work (paper / preprint / book) — metadata + abstract |
