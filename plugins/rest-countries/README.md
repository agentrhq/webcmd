# webcmd-plugin-rest-countries

Webcmd commands for rest-countries.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/rest-countries
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd rest-countries country` | Look up countries by name (common / official, substring match) |
| `webcmd rest-countries region` | List countries in a region (africa / americas / asia / europe / oceania / antarctic) |
