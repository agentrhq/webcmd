# webcmd-plugin-producthunt

Webcmd commands for producthunt.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/producthunt
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd producthunt browse` | Best products in a Product Hunt category |
| `webcmd producthunt hot` | Today's top Product Hunt launches with vote counts |
| `webcmd producthunt posts` | Latest Product Hunt launches (optional category filter) |
| `webcmd producthunt today` | Today's Product Hunt launches (most recent day in feed) |
