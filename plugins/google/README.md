# webcmd-plugin-google

Webcmd commands for google.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/google
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd google images` | Search Google Images for photos and image results |
| `webcmd google news` | Get Google News headlines |
| `webcmd google search` | Search Google |
| `webcmd google suggest` | Get Google search suggestions |
| `webcmd google trends` | Get Google Trends daily trending searches |
