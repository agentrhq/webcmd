# webcmd-plugin-npm

Webcmd commands for npm.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/npm
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd npm downloads` | Daily download counts for an npm package over a window |
| `webcmd npm package` | Single npm package metadata (latest version, license, homepage, repository). Use `npm downloads` for stats. |
| `webcmd npm search` | Search the public npm registry by keyword |
