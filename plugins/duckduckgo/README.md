# webcmd-plugin-duckduckgo

Webcmd commands for duckduckgo.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/duckduckgo
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd duckduckgo search` | Search DuckDuckGo |
| `webcmd duckduckgo suggest` | DuckDuckGo search suggestions |
