# webcmd-plugin-dblp

Webcmd commands for dblp.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/dblp
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd dblp author` | List dblp publications by a given author (newest first; resolves to top PID match) |
| `webcmd dblp paper` | Fetch a dblp record by canonical key (e.g. conf/nips/VaswaniSPUJGKP17) |
| `webcmd dblp search` | Search dblp computer-science bibliography by free-text query |
| `webcmd dblp venue` | Search dblp venue registry (conferences / journals) by name or acronym |
