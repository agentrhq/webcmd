# webcmd-plugin-lichess

Webcmd commands for lichess.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/lichess
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd lichess top` | Top-N Lichess leaderboard for a perf type (bullet/blitz/rapid/classical/...) |
| `webcmd lichess user` | Fetch a Lichess player profile by username (rating, perfs, counts) |
