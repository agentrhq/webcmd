# webcmd-plugin-semanticscholar

Webcmd commands for semanticscholar.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/semanticscholar
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd semanticscholar citations` | List papers that cite a Semantic Scholar paper (paginated) |
| `webcmd semanticscholar paper` | Semantic Scholar paper detail (citation graph + AI tldr) by paperId, DOI, or arXiv id |
| `webcmd semanticscholar recommendations` | Semantic Scholar AI-curated related papers for a paperId, DOI, or arXiv id |
| `webcmd semanticscholar search` | Search Semantic Scholar papers by free text |
