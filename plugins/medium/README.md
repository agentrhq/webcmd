# webcmd-plugin-medium

Webcmd commands for medium.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/medium
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd medium feed` | Medium popular posts Feed |
| `webcmd medium search` | Search Medium posts |
| `webcmd medium tag` | Latest Medium articles tagged with a given keyword (RSS feed) |
| `webcmd medium user` | Get Medium user posts |
