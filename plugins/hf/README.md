# webcmd-plugin-hf

Webcmd commands for hf.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/hf
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd hf datasets` | Top Hugging Face datasets (downloads / likes / trending / freshness). |
| `webcmd hf login` | Open hf login |
| `webcmd hf models` | Top Hugging Face models (downloads / likes / trending / freshness). |
| `webcmd hf paper` | Hugging Face paper detail by arXiv id (full title / summary / authors / AI keywords) |
| `webcmd hf spaces` | Top Hugging Face Spaces (likes / created_at / last_modified). |
| `webcmd hf top` | Top upvoted Hugging Face papers |
| `webcmd hf whoami` | Show the current logged-in hf account |
