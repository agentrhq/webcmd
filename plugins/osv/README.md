# webcmd-plugin-osv

Webcmd commands for osv.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/osv
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd osv query` | OSV.dev vulnerabilities affecting a package (optionally pinned to a version) |
| `webcmd osv vulnerability` | Single OSV.dev vulnerability detail (severity, affected packages, CVE/GHSA aliases) |
