# webcmd-plugin-tvmaze

Webcmd commands for tvmaze.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/tvmaze
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd tvmaze search` | TVmaze TV show search by title (returns id, name, network, premiered/ended, rating) |
| `webcmd tvmaze show` | Single TVmaze TV show detail by id (network, schedule, rating, IMDB/TheTVDB cross-refs) |
