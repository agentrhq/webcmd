# webcmd-plugin-devto

Webcmd commands for devto.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/devto
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd devto latest` | Newest dev.to articles (firehose, all tags) |
| `webcmd devto read` | Read a DEV.to article body by id |
| `webcmd devto tag` | Latest DEV.to articles for a specific tag |
| `webcmd devto top` | Top DEV.to articles of the day |
| `webcmd devto user` | Recent DEV.to articles from a specific user |
