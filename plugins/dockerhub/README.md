# webcmd-plugin-dockerhub

Webcmd commands for dockerhub.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/dockerhub
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd dockerhub image` | Fetch a Docker Hub repository's public metadata (stars, pulls, last updated, status) |
| `webcmd dockerhub search` | Search Docker Hub repositories by keyword |
