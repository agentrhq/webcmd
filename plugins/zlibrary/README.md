# webcmd-plugin-zlibrary

Webcmd commands for zlibrary.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/zlibrary
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd zlibrary info` | Get book details and available download formats from a Z-Library book page |
| `webcmd zlibrary search` | Search Z-Library for books by title, author, ISBN, or keyword |
