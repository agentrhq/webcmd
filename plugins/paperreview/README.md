# webcmd-plugin-paperreview

Webcmd commands for paperreview.

## Install

```bash
webcmd plugin install github:agentrhq/webcmd/paperreview
```

## Commands

| Command | Description |
| --- | --- |
| `webcmd paperreview feedback` | Submit feedback for a paperreview.ai review token |
| `webcmd paperreview review` | Fetch a paperreview.ai review by token |
| `webcmd paperreview submit` | Submit a PDF to paperreview.ai for review |
